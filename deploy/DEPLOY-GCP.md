# Деплой PayOut на Google Cloud (бесплатно)

Результат: стенд круглосуточно работает по адресу `https://…sslip.io` с HTTPS. Домен покупать не нужно.
Время: около 20 минут. Всё делается в браузере, SSH-ключи не нужны.

## Шаг 1. Аккаунт (~5 мин)

1. Откройте https://cloud.google.com/free и нажмите **Get started for free**. Войдите Google-аккаунтом.
2. Укажите страну и карту. Карта нужна для проверки, списаний в пределах бесплатных лимитов нет. Новые аккаунты дополнительно получают пробный кредит.
3. Сразу защититесь от случайных расходов: ☰ → **Billing → Budgets & alerts → Create budget**, сумма **$1**, оповещение на email.

## Шаг 2. Бесплатная машина (~5 мин)

☰ → **Compute Engine → VM instances**. При первом входе нажмите **Enable API** и подождите минуту. Затем **Create instance** и заполните поля **строго так**, иначе машина будет платной:

| Поле | Значение |
|---|---|
| Name | `payout` |
| Region | **us-central1 (Iowa)**, **us-east1** или **us-west1** — только эти три бесплатны |
| Machine type | Series **E2** → **e2-micro** |
| Boot disk → Change | OS **Ubuntu**, версия **Ubuntu 24.04 LTS (x86/64)**, тип **Standard persistent disk**, размер **30 GB** |
| Firewall | ✅ **Allow HTTP traffic**, ✅ **Allow HTTPS traffic** |

Нажмите **Create**. Через минуту машина станет зелёной ✅, а в колонке **External IP** появится её адрес.

## Шаг 3. Загрузка и установка (~10 мин)

1. В строке машины нажмите кнопку **SSH**: откроется терминал прямо в браузере.
2. В окне терминала нажмите **⚙ / Upload file** (значок со стрелкой вверх) и выберите `payout.zip`.
3. Вставьте в терминал и нажмите Enter (`ваш@email.ru` замените своим, он нужен для HTTPS-сертификата):

```bash
sudo apt-get update && sudo apt-get install -y unzip && unzip -o payout.zip && cd payout && sudo bash deploy/install.sh --domain auto --email ваш@email.ru --password Test2026
```

Скрипт сам:
- добавит файл подкачки (у бесплатной машины всего 1 ГБ памяти);
- поставит Node.js и Caddy;
- выпустит HTTPS-сертификат;
- запустит сервис с автозапуском.

В конце он напечатает адрес вида `https://34-123-45-67.sslip.io`.

`--password Test2026` закрывает стенд от посторонних: браузер спросит логин (любой) и этот пароль. Уберите параметр, если стенд должен быть открытым.

## Шаг 4. Проверка

Откройте адрес из вывода скрипта. Сертификат выпускается примерно за минуту: если сразу не открылось, обновите страницу.

|---|---|
| Компания (владелец) | demo@payout.ru |
| Бухгалтер / менеджер | buh@payout.ru / manager@payout.ru |

## Полезно знать

- **IP может смениться**, если остановить и снова запустить машину: адрес sslip.io тогда тоже поменяется. В этом случае повторите команду из шага 3. Не останавливайте машину без необходимости. Перезагрузка (Reset) IP не меняет.
- **Свой домен** можно подключить позже: A-запись домена на IP машины, затем `sudo bash deploy/install.sh --domain ваш-домен --email ваш@email.ru`.
- **Бесплатные лимиты:** одна e2-micro, 30 ГБ стандартного диска и 1 ГБ исходящего трафика в месяц. Для теста этого хватает. Первые дни поглядывайте в Billing, чтобы убедиться, что расходов нет.

Обслуживание (в SSH-терминале):

```bash
journalctl -u payout -f                      # логи
sudo systemctl restart payout                # перезапуск
sudo bash /opt/payout/deploy/reset-demo.sh   # вернуть исходные демо-данные
```
