Для разработчиков

Open API без NDA

REST + JSON. Ключ создаётся в кабинете в разделе «Интеграции». Все суммы указываются в рублях.

Аутентификация

Передавайте ключ в заголовке X-Api-Key.

curl https://payout.example/api/v1/balance -H "X-Api-Key: po_live_…"
GET/api/v1/balance

Текущий баланс номинального счёта.

GET/api/v1/contractors

Список исполнителей и статус НПД.

POST/api/v1/contractors

Добавить исполнителя. Статус НПД проверяется сразу.

{ "type": "npd", // npd | ip | fl | eaeu "full_name": "Иван Петров", "inn": "500100732259", "phone": "+79001234567", "card": "2200000000000004" }
GET/api/v1/payouts?status=paid&since_id=100

Последние 500 выплат со статусами и номерами чеков. GET /api/v1/payouts/:id — одна выплата.

POST/api/v1/payouts

Создать и сразу отправить выплату. Перед отправкой выполняются риск-проверки. Передавайте заголовок Idempotency-Key: повторный запрос с тем же ключом вернёт уже созданную выплату, а не создаст вторую.

{ "contractor_id": 42, "amount": 15000, "purpose": "Оплата по акту А-2026-0012" } → { "id": 381, "status": "processing", "commission": 285, "tax": 900, "net": 14100 }

Вебхуки

Укажите URL в кабинете. Мы отправляем POST с JSON о событиях payout.paid, payout.failed и document.signed. При ошибке — до 6 повторов с нарастающей паузой.

Каждый запрос подписан: заголовки X-PayOut-Timestamp и X-PayOut-Signature. Проверяйте подпись секретом из кабинета:

expected = "sha256=" + HMAC_SHA256(secret, timestamp + "." + raw_body).hex() if not compare_digest(expected, request.headers["X-PayOut-Signature"]): reject()
{ "event": "payout.paid", "data": { "id": 381, "amount": 15000, "contractor_id": 42, "receipt": "20a1b2c3d4e5" }, "ts": "2026-11-16T10:00:00Z" }

Ошибки

Ответ с кодом 4xx содержит поле error с понятным текстом на русском. Например, 402 означает «Недостаточно средств», 422 — что выплата заблокирована риск-проверкой, 429 — превышен лимит 600 запросов в минуту.

Проверка подлинности документов

GET /api/public/verify/:sha256 — публичная проверка подписанного документа по контрольной сумме (также страница /verify/:sha256).
